# FIRMMIT ONE TV 쇼룸 (`fm-one-showroom`)

사내 TV 에 상시 띄워 두고, 손님이 오면 리모컨으로 넘겨 가며 설명하는 **방문객용 화면**이다.

> **직원 허브(`fm-one-hub`)와 완전히 분리된다.** 배포 단위 · 데이터 · 세션 · 쿠키 · D1 을 공유하지 않고,
> 쇼룸 코드는 허브 API 를 부르지 않는다. 브랜드 색과 로고 파일만 같은 것을 쓴다.

| 항목 | 값 |
|---|---|
| Worker | `fm-one-showroom` (정적 자산 전용) |
| 저장소·비밀값 | **없음** — D1 · KV · 환경 변수 · Secret · Cron 모두 없음 |
| 외부 요청 | **0건** — 글꼴·이미지·스크립트·QR 전부 로컬. 외부 CDN·분석 스크립트 없음 |
| 브라우저 저장소 | 서비스 워커 Cache Storage 만. `localStorage`·`sessionStorage`·IndexedDB·쿠키 안 씀 |
| 방문객 입력 | 없음 (폼·로그인 없음) → 화면에 아무것도 남지 않는다 |
| 현재 콘텐츠 | **샘플이다 (G10).** 화면에 "샘플 — 승인 전" 이 계속 표시된다 |

---

## 1. 구조

```text
apps/showroom/
├─ wrangler.jsonc          fm-one-showroom (자산 전용. D1·vars·triggers 없음)
├─ content/
│  ├─ manifest.json        콘텐츠 정본 — 승인·게시 기간·언어별 문구
│  ├─ manifest.schema.json 그 형식 (JSON Schema 2020-12)
│  └─ media/               그림 (지금은 승인 전 자리표시자 SVG)
├─ scripts/
│  ├─ check-content.mjs    내보내기 전 검사 (하나라도 걸리면 빌드 실패)
│  └─ build-content.mjs    검사 → media 복사 → QR 생성 → public/content.json
├─ public/                 배포되는 것 (index.html · app.js · styles.css · sw.js · _headers · content.json · media/)
└─ test/
   ├─ content.test.mjs     검사기·화면 코드 규칙 시험
   ├─ ui_showroom.py       Playwright 화면·조작·오프라인 시험
   └─ screens/             캡처와 결과
```

## 2. 실행·시험

```bash
cd apps/showroom
npm run build      # 검사 → QR 생성 → public/content.json (검사 실패면 아무것도 쓰지 않음)
npm test           # 검사 + content.test.mjs
npm run test:ui    # Playwright(Chromium) 화면 시험 → test/screens/
npm run build:dry  # wrangler deploy --dry-run (로그인 불필요, 실제 배포 아님)
```

`npm run test:ui` 는 `playwright` 와 **`opencv-python-headless`** 가 필요하다.
후자는 만들어진 QR 을 **다른 구현으로 다시 읽어** 실제로 그 공개 주소로 가는지 확인하는 데 쓴다
(방문객이 찍는 코드라 "만들어졌다" 만으로는 부족하다).

| 시험 영역 | 확인 내용 |
|---|---|
| 콘텐츠 검사 | 승인 정보 없음 · 기간 역전 · 파일 없음 · 이메일 · 전화번호 · 내부 배포 주소(workers.dev·vercel.app·pages.dev) · 구글 문서 주소 · 시트 ID 형태 · IP · http · 스크립트 태그 · 허용 밖 링크 · 언어 빠짐 · id 중복 — **22가지가 모두 빌드 실패**. 정상 승인 묶음은 통과(대조군) |
| 화면 코드 | 브라우저 저장소 미사용 · HTML 문자열 미사용 · 외부 주소 없음 · iframe 없음 · 폼 없음 · 허브 API 미호출 · CSP · 숨김이 실제 숨김 |
| 조작 | 자동재생 진행 · 입력 시 정지 · 멈춘 동안 안 넘어감 · ← → 이동 · Home 목차 열고 닫기 · ↑↓ 언어 |
| 표시 조건 | draft·만료·회수 항목이 화면·목차에 없음. 시계를 바꿔 게시 전(안전 화면)·게시 중·만료 후 확인 |
| 상시 전시 | 네트워크를 끊고 새로고침해도 화면이 뜸(서비스 워커 저장본) · 저장본이 없으면 안전 화면 |
| QR | 3개가 만들어지고, 독립 디코더로 읽어 **공개 주소와 정확히 일치** |
| 화면 | 1920×1080 · 3840×2160 에서 16:9 유지 · 가로 넘침 0 · 콘솔 오류 0 · **외부 요청 0건** |

## 3. 콘텐츠 승인 절차

콘텐츠는 `content/manifest.json` 하나로 관리한다. **승인 → 게시 → 표시 → 만료·회수**가 이 파일 안에서 끝난다.

1. **작성** — 항목을 `status: "draft"` 로 추가한다. draft 는 화면에 나오지 않는다.
2. **승인** — 소유자(경영관리부·해외사업부 등)가 문구·사진을 확인한다.
   - `approved_by` 에는 **직책만** 적는다(실명 금지 — 검사기가 한글 2~4자 값을 막는다).
   - `approved_at` 에 승인일(YYYY-MM-DD)을 적는다.
3. **게시** — `status: "published"` 로 바꾸고 `publish_from` · `expires_at` 을 정한다.
   화면은 **게시 상태이면서 오늘이 기간 안**일 때만 보여준다.
4. **회수** — `status: "withdrawn"` 으로 바꾼다. 즉시 화면에서 빠진다.
5. **내보내기** — `npm run build`. 검사를 통과하지 못하면 아무것도 쓰지 않는다.
6. **배포** — §4.

### 샘플에서 실제 콘텐츠로 (G10)

지금은 `release.status: "sample"` 이라 모든 항목의 `approved_by` 가 `"SAMPLE"` 이고 화면에 **"샘플 — 승인 전"** 이 계속 뜬다.
실제 콘텐츠로 바꿀 때:

- `release.status` 를 `"approved"` 로 바꾸고, 모든 항목에 **직책**과 **승인일**을 넣는다.
- `content/media/` 의 자리표시자 SVG 를 승인된 사진으로 바꾼다.
- **지어내지 않는다** — 온실 사례·매출 수치·고객명은 승인된 것만 넣는다.
- 사진·고객 사례의 **권리와 공개 승인**을 별도로 기록한다.

### 넣으면 안 되는 것

이메일 · 전화번호 · 직원 실명 · 내부 배포 주소(`*.workers.dev` · `*.vercel.app` · `*.pages.dev`) ·
구글 문서·시트 주소나 ID · 고객 연락처 · 미수금·매입원가·마진 · 직원 인증이 필요한 앱 주소.
**검사기가 막지만, 막힌다고 안심하지 말고 애초에 넣지 않는다.**

### 링크

화면에 QR 로 나갈 수 있는 주소는 **공개 주소 3개**뿐이다 (`scripts/check-content.mjs` 의 허용 목록).

| id | 주소 |
|---|---|
| `mall` | `https://firmmitmall.com` |
| `kr` | `https://www.firmmit.kr` |
| `telegram` | `https://t.me/firmmit_global` |

다른 주소를 넣으면 빌드가 실패한다. 스마트스토어·퍼밋프레시처럼 **확인되지 않은 주소는 추정해서 넣지 않는다.**

## 4. 배포 안내 (FIRMMIT 담당자 직접 수행)

> 쇼룸에는 비밀값·개인정보가 없지만, **승인된 콘텐츠만** 올라가야 한다.
> 배포 전에 `npm test` 와 `npm run test:ui` 가 모두 통과해야 한다.

1. `npm run build` → 검사 통과 확인 (`# 문제 0건`)
2. `npx wrangler login` (회사 소유 계정)
3. `npx wrangler deploy` → 나온 주소로 접속해 화면 확인
4. 최종 주소는 별도로 정한다. `show.firmmit.com` 은 **아직 개설·승인된 사실이 없다** `[재확인 필요]` —
   정해질 때까지 workers.dev 주소를 쓰되, 그 주소는 방문객 화면·문서에 적지 않는다.
5. TV 쪽 설정(키오스크 모드·자동 실행·전체 화면)은 **기기 설정**이다. 웹페이지가 대신 할 수 없다.
   - 사내 TV 의 브라우저 또는 연결된 PC 에서 시작 페이지로 지정하고 전체 화면으로 연다.
   - 절전·화면 보호기는 기기 설정에서 끈다(웹의 Screen Wake Lock 은 보조 수단이다).

### 조작

| 키 | 동작 |
|---|---|
| ← → | 이전 · 다음 |
| Enter | 다음 (목차가 열려 있으면 닫기) |
| Home · 리모컨 뒤로 | 목차 열기/닫기 |
| Space | 자동재생 켜기/끄기 |
| ↑ ↓ | 언어 바꾸기 |
| End | 마지막 장 |

**입력이 들어오면 자동재생이 멈추고**, `idle_resume_seconds`(기본 60초) 동안 입력이 없으면 다시 돈다.
마우스·휠·터치도 같은 방식으로 멈춘다 — 발표 중에 갑자기 넘어가지 않게 하기 위해서다.

## 5. G09 현장 시험 체크리스트 (FIRMMIT 수행)

로컬 시험으로는 확인할 수 없는 것들이다. **실제 TV 에서** 확인한다.

- [ ] 사내 TV 해상도에서 글자가 멀리서 읽히는가 (서 있는 거리에서 확인)
- [ ] 가장자리 여백 안에 내용이 다 들어오는가 (오버스캔 확인 — EBU R 95 5% 기준으로 만들었다)
- [ ] 실제 **리모컨**의 방향키·확인키·뒤로가 동작하는가 (기기마다 키 코드가 다르다)
- [ ] **24시간 연속** 켜 두고 화면이 꺼지거나 멈추지 않는가
- [ ] **재부팅** 뒤 자동으로 쇼룸이 뜨는가 (기기 설정)
- [ ] **절전**에서 깨어난 뒤 정상인가
- [ ] **네트워크 단절** 상태에서 화면이 계속 도는가 (서비스 워커 저장본)
- [ ] 네트워크가 끊긴 채로 **만료일이 지나면** 그 항목이 사라지는가
- [ ] 저장본을 지우고(브라우저 데이터 삭제) 네트워크 없이 열면 **안전 화면**이 뜨는가
- [ ] QR 을 **실제 휴대폰**으로 찍어 공개 주소가 열리는가
- [ ] 방문객이 화면을 만졌을 때 내부 정보가 보이는 경로가 없는가

## 6. 알려진 한계

- **승인된 콘텐츠가 아직 없다 (G10).** 지금 화면은 전부 자리표시자이며 "샘플 — 승인 전" 이 계속 표시된다.
- **최종 언어 목록은 FIRMMIT 결정 대기.** 지금은 `ko` · `en` 두 가지다. `uz-Latn` · `ru` 는 문구를 넣으면 바로 쓸 수 있다.
- **최종 주소 미정** `[재확인 필요]` — `show.firmmit.com` 개설·DNS 변경은 승인된 사실이 없다.
- **키오스크·자동 실행·전체 화면은 기기 설정**이다. 웹페이지가 보장하지 않는다.
- **오프라인 중에는 회수를 즉시 반영할 수 없다.** 네트워크가 끊긴 TV 는 서버의 회수를 알 수 없으므로,
  게시 기간(`expires_at`)을 짧게 잡는 것이 유일한 방어다. 중요한 회수는 현장에서 화면을 끄거나 새로고침해야 한다.
- **시험의 "24시간" 은 자동 시험이 아니다.** 초 단위 시계 조작으로 표시 규칙만 확인했다 — 실제 장시간 시험은 G09 다.
- **CCTV 영상은 넣지 않았다.** R3 트랙(모델·위치·녹화 정책 미확인)은 이번 범위 밖이다.
